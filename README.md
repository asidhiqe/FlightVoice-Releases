# FlightVoice releases

Downloads for **FlightVoice** (live cabin, cockpit and ground announcements plus a stream overlay for MSFS 2020 / 2024).
This repository only holds release files. There is no source code here.

## Install

1. Get the files listed in the release notes (the installer, the app zip and the voice models) into one folder.
2. Double-click `INSTALL.bat`.
3. The Setup guide opens by itself.

## Update

Updates are published here as **Releases** (a small `FlightVoice-X.Y.Z-update.zip` per version). Put the update zip next to
`INSTALL.bat` and run it again; your settings, logo, voices and flight history are kept.

## Uninstall

Double-click `UNINSTALL.bat`. It shows what it removes and can save a backup of your settings first.
